## Dokumentation pflegen

Jede Information hat einen Hauptort im passenden Fachbereich. Andere Seiten verlinken dorthin. Die Projekt-README enthält Schnellstart und Einstieg; der Ist-Stand bleibt eine kurze Gesamtübersicht. Planungen und Versionshistorie werden getrennt geführt.

Neue Anleitungen beschreiben Zweck, Voraussetzungen, Schritte, erwartetes Ergebnis und typische Fehler, soweit diese Punkte zutreffen. Befehle gelten aus dem Repository-Stamm. Bei RI-Funktionen zwischen vorhanden, vorbereitet und geplant unterscheiden. Unterordner erhalten bei mehreren fachlichen Themen einen eigenen Einstieg; weitere Dateien entstehen bei ausreichendem Inhalt. Versionierte Formatbeispiele liegen unter `examples/`.
